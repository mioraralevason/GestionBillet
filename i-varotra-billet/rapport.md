# 📱 iBillet

Application de gestion de billets et d’événements avec interface moderne, mode sombre et fonctionnalités avancées de suivi et de scan.

---

## 🚀 Fonctionnalités principales

- Gestion des événements
- Gestion des billets (multi-types, multi-prix)
- Scan avec reconnaissance de type
- Dashboard analytique
- Personnalisation du thème
- Interface moderne (mode sombre)

---

## 🔐 Authentification

- Connexion **asynchrone**
- Connexion **non automatique** (manuelle)

---

## 🧭 Interface Administrateur

### Navigation
- Header sombre avec menu burger :
  - 📅 Calendrier
  - 👤 Acheteurs
  - 🎉 Événements
  - ℹ️ À propos

### Menu latéral
- Mode réduit : icônes uniquement
- Élément actif : texte affiché
- Design :
  - Arrondi
  - Flottant (non collé en bas)

---

## 🏠 Pages principales

- Accueil
- Événements
- Scan

## 📊 Dashboard

### Design
- Style électro
- Mode sombre

### Fonctionnalités
- Filtre par période :
  - Mois
  - Année

### Contenu
- Activités récentes (3 dernières) :
  - Icône
  - Billets vendus
  - Total billets

### UI
- Header avec recherche (à droite)
- Icône dashboard non cliquable
- Suppression :
  - Message "Bonjour"
  - Bouton déconnexion
